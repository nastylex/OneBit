# 🎧 OneBEAT

**Experience music like never before.**

Stream your favorite songs, discover new artists, create personalized playlists, and enjoy crystal-clear audio — all in one place. Built for every music lover, our platform delivers seamless listening anytime, anywhere.

## 🚀 About

OneBEAT is a music streaming platform currently on the web. This repository contains the official OneBEAT landing page — a polished, fully responsive single-page site built with pure HTML, CSS, and vanilla JavaScript (no frameworks, no build step).

## ✨ Features

- **Crystal-clear audio** — lossless Hi-Fi streaming up to 24-bit
- **Smart discovery** — radio that learns your taste and surfaces rising artists
- **Personalized playlists** — AI mixes that update with your mood
- **Offline listening** — download tracks and playlists for anywhere
- **Real-time lyrics** — synced, karaoke-style lyrics in many languages
- **Cross-device sync** — phone, web, TV, and car

## 🖥️ Preview

Open `index.html` directly in any browser, or run the local preview server:

```bash
node preview-server.js
```

Then visit `http://localhost:8123`.
